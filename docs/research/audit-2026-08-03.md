# Research audit — 2026-08-03 shipped slices

An independent research audit validated the shipped work (main through `2448e6e`, multi-pin
`f423305`, via-aware `9c903fd`; ADRs 0011-0020) against 2023-2026 literature. Verdicts and the
resulting follow-ups are recorded here; sources are listed at the end.

## Verdicts

| Area | Verdict | Key finding |
|---|---|---|
| Circuit Intent IR → deterministic schematic (ADR-0014/0015) | ALIGNED | Inverts the emit-then-validate pattern of AnalogCoder/Schemato/EEschematic/PCBSchemaGen; matches the typed circuit-as-data seam of tscircuit/atopile/SKiDL. No public kicad-mcp server has a validated intent contract. |
| Exact-integer envelopes and cores | DEFENSIBLY-DIVERGENT | Envelopes are classic conservative L-infinity dilation (Lozano-Perez, k-DOPs). Under-approximating attachment cores are bespoke: standard connectivity engines use exact shape intersection; our under-approximation is a deliberate trade that errs toward under-connection. Bignum-integer arithmetic sidesteps the Shewchuk/CGAL robust-predicate problem entirely. |
| Multi-pin MST-over-components (ADR-0019) | ALIGNED | The per-leg multi-source search into the growing component is the Takahashi-Matsuyama (1980) Steiner heuristic; Hwang 1976 gives the rectilinear MST 3/2 bound (obstacle-free terminals only — the bound does not transfer to component-gap MST over obstacle legs). |
| Via-aware connectivity (ADR-0020) | ALIGNED | Layer-set + overlap matches LVS/extraction practice (Magic, connectivity-based extraction); the annulus core is physically stricter than KiCad's own circle test, erring toward under-connection. |
| Rotation-fix methodology | ALIGNED | Textbook pseudo-oracle/differential testing. The gap the bug exposed is the missing complement: metamorphic relations (rotation/reflection invariance) catch this class without an oracle. |
| Release/evidence discipline | ALIGNED (substance), naming gap | DRC-as-retained-evidence is structurally an in-toto attestation; release-ledger rows are SLSA-style provenance; the append-only ledger is a human-scale transparency log without cryptographic tamper-evidence. Adopt the standard vocabulary. |
| Fill authority (concept) | ALIGNED | The freshness-bound trust model is a "verifying trace" (Build Systems a la Carte, JFP 2020); cite it in ADR-0021. |

Overclaim check: clean — the ADRs' negative claims and correction discipline were assessed as
unusually rigorous. Behind-technique check: PathFinder-style negotiation remains roadmapped, staged
behind declared policy slots, consistent with the 2024-2026 pattern of learning applied to
ordering/batching/cost-weights only.

## Prioritized follow-ups

1. Metamorphic test family over the preview pipeline: whole-board rotation, reflection,
   translation, endpoint swap — outcomes and DRC counts must be invariant. (tests, small; highest
   leverage)
2. ADR-0019: cite Hwang 1976 with the non-transfer caveat; name Takahashi-Matsuyama; one sentence
   on the determinism-motivated fixed edge order divergence. (docs)
3. Ledger/security docs: adopt attestation/provenance/transparency-log terminology; state the
   ledger's non-cryptographic append-only nature; consider in-toto Statement format for DRC
   evidence. (docs + small design option)
4. ADR-0021: cite verifying traces. (done in the fill-authority slice)
5. Routing baseline: name exact intersection as the standard connectivity model and
   under-approximation as deliberate divergence; note the pad-core / pin-access-point
   correspondence; cite Shewchuk/CGAL for the exactness stance. (docs)
6. ADR-0014: add PCBSchemaGen and tscircuit/atopile/SKiDL as practice context. (docs)
7. Mark post-cutoff arXiv IDs in docs/research with verification dates. (docs hygiene)

## Source verification

Pre-2026 literature cited above was confirmed on 2026-08-03. Identifiers in the `2512.*`, `2602.*`,
`2605.*` and `2607.*` arXiv ranges post-date the auditing tooling's knowledge cutoff and could not
be confirmed; `2602.00510` (PCBSchemaGen) is recorded as reported rather than verified. No decision
in this repository rests on an unconfirmed identifier.
