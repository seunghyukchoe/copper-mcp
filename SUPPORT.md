# Support

CopperMCP is a community project in pre-alpha development.

- Use **GitHub Discussions** for setup questions, design exploration, and algorithm ideas.
- Use an **issue form** for reproducible bugs, accepted feature proposals, or benchmark work.
- Use **GitHub Private Vulnerability Reporting** for security issues.

Before requesting support, run `copper-mcp info`, record your Python and KiCad versions, search
existing issues, and reduce failures to a sanitized or synthetic board. There is no guaranteed
response time or commercial support commitment.
